# QQ宠物(2005–2018)单机复刻 · 完整功能规格

> 资料来源:2006 年官方公告存档(t086.com)、CSDN/cnblogs 时代攻略、机核长文、百度知道详答、
> 以及 2024 年怀旧服 v1.2.4 逆向工程数据(github.com/xuemian168/qqpet_automation)。
> 注意:QQ宠物 2006-08 有过一次大改版。「旧版」=2005~2006 初,「新版」=2006-08 之后(大多数人记忆中的版本)。
> 复刻建议以新版为基准。标注「⚠推测」的是未找到原始数值、需要自行设计的部分。

## 0. 宠物种类与领养

- **QQ企鹅**(唯一贯穿始终的宠物):公企鹅红围巾(QGG),母企鹅粉围巾(QMM)。每个账号限养一只。
- 其他官方宠物:QQ猪猪(2007)、熊熊,均 2013-06 下线。没有"QQ猴"。
- 领养:官网砸蛋免费领养(选性别),或好友赠送宠物蛋孵化(二代宠物,名片带父母信息)。
- 初始赠送:房子 + 还魂丹×1 + 300 元宝(另一说 500)。

## 1. 属性面板(核心数值)

四大属性 + 成长值/等级:

| 属性 | 范围 | 说明 |
|---|---|---|
| 饥饿值 | 0 ~ (3000+等级×100) | 30 级封顶上限 6000 |
| 清洁值 | 0 ~ (3000+等级×100) | 同上 |
| 心情值 | 0~1000 | 打工时封顶 600,学习时封顶 900 |
| 健康值 | 5 档 | 5=健康,4→1 四级病情,0=死亡 |

**状态档位**(占上限百分比):
- 饥饿:吃撑了 ≥60% / 吃得很饱 ≥36% / 不饿 ≥24% / 有点饿 ≥12% / 以下饥饿
- 清洁:干干净净 ≥72% / 好痒啊 ≥48% / 蓬头垢面 ≥24% / 以下脏

**衰减速度**:
- 平时/学习/休息:饥饿 -2/分钟,清洁 -2/分钟(每小时各 120 点 ≈ 10 元宝/小时维持成本,这是整个经济系统的锚)
- 打工时(新版,按等级):0-5 级 饥饿3.2+清洁4.4/分(≈18元宝/时) → 6-11级 22/时 → 12-17级 26/时 → 18级+ 饥饿5.0+清洁8.0/分(≈30元宝/时)
- 心情:自然缓慢下降;饥饿/清洁变黄不处理时心情约 -15/分钟;冒对话泡不理也扣心情
- 怀旧服实现参考:每 60 秒 tick,饥饿/清洁 -5~8(心情<600 额外 -2),心情 -2~4;饥饿<720 = 饥饿状态,清洁<1080 = 脏

**心情恢复**(2006 官方公告):
- 鼠标点击宠物 +100/分钟;喂食或洗澡 +150/分钟;玩具 +100/分钟;聊天 +50/分钟;桌面小游戏 +50/分钟
- 经典技巧:挂着小游戏窗口不玩也能保持心情满

## 3. 喂食

- 双击宠物身体 → 快速喂养对话框(带智能提示:饿了提示喂食、脏了提示洗澡);右键菜单也可进。
- 官方比价公式:饥饿类 10 元宝 ≈ 180 点饥饿(1 元宝 = 18 点)。
- 已证实条目:香瓜果冻 60 元宝 +1080 饥饿;鱼形曲奇饼 60 元宝 +1080(旧版加武力);旧版 40 元宝食物 +720 饥饿 +8 属性。新版食物不再加属性。
- ⚠推测:完整货架清单未找到,按比价公式自造:小份 20 元宝/360 点 → 大份 120 元宝/2160 点,溢价品附加心情。

## 4. 清洁/洗澡

- 香皂、毛巾 = 20 元宝,+720 清洁。比价:10 元宝 ≈ 360 点(比食物便宜一半)。
- 洗澡即时恢复 + 心情加成。生病时别急着喂/洗:药品自带饥饿/清洁恢复,会溢出浪费。

## 5. 生病 · 医疗

**诱因**:饥饿/清洁过低(变黄)、心情 <500。病情放置会沿疾病链加重直至死亡,生病时说特征台词提示病名。

**三条疾病链**(健康档 4→3→2→1→死):
1. 感冒链:感冒(板蓝根)→ 发烧(退烧药)→ 重感冒(银翘丸)→ 肺炎(金色消炎药水)→ 死
2. 咳嗽链:咳嗽(枇杷糖浆)→ 支气管炎(甘草剂)→ 哮喘(定喘丸)→ 肺结核(通风散)→ 死
3. 肠胃链:肚子胀(消食片)→ 胃炎(蓝色消炎药水)→ 胃溃疡(龙胆草)→ 胃癌(仙人汤)→ 死
另有「垂危」状态用通风散。

**看病**:必须去医院开处方 50 元宝;药价:不舒服 20 / 小病 80 / 重病 120 / 绝症 200 元宝。吃错药病情加重(所以必须开处方,不能瞎买药——这是设计意图)。

## 6. 死亡 · 复活

- 疾病链走到底即死,进坟墓。
- **还魂丹**:4 Q币 或 400 元宝(粉钻 320),复活保留全部等级/成长/财产。初始送 1 颗。
- **埋葬**:资料全部清空,重新领养从头开始。
- ⚠推测:坟墓界面细节(墓碑样式、悼词)未找到。

## 8. 学习/上学

- 三系 × 三科 = 9 门课:武力系(武术/劳技/体育)、智力系(政治/数学/语文)、魅力系(礼仪/音乐/美术)。课程加对应三围属性 + 发文凭解锁职业。
- 三学段:小学(6 级入学)→ 中学(12 级)→ 大学(约 18 级)。进阶规则:学中学某系任一课,须先修完小学该系全部 3 门;大学同理。
- 课时:小学 8 节/6 小时,中学 20 节/15 小时,大学 40 节/30 小时。单系直通大学 ≈ 93 小时(攻略共识的最优路线)。
- 无独立学费,成本 = 上学期间的正常喂养消耗;学习时心情封顶 900。
- 奖学金:单课小学 20 / 中学 50 / 大学 100 元宝;整段一次性小学 150(12 级后领 250)、中学 450,各限一次。
- ⚠推测:毕业考试机制(有 74 题题库流传但机制不详)。

## 9. 结婚 · 生蛋 · 二代

- **条件**:双方 ≥15 级、异性(QGG×QMM)、同代非近亲;求婚方持婚戒。
- **戒指**:12 级可到教堂"小天使"处免费领「挚爱金戒」;更贵的去教堂珠宝店买,戒指越贵爱情值越高 → 蛋越多、后代属性越好。⚠推测:付费戒指价目表(建议 3-5 档)。
- **流程**:社区 → 风语广场教堂 → NPC 凯西配对(可指定好友宠物)→ 出示戒指 → 对方同意 → 神父主持婚礼。
- **生蛋**:婚后累计在线 200 小时,由母方到教堂找神父"特里斯坦"点「培育宠物蛋」,得 1 或多只蛋;此后每次再 +200 小时;一生限 10 次。
- **分蛋**:按双方爱情值比例分;爱情值 = 戒指爱情值 + 婚后成长值×10。
- **蛋**:可赠好友(我的家→家庭资料→赠送好友),好友孵化出二代宠物(名片显示父母昵称、出生日期)。⚠推测:孵化时长、属性继承公式。
- **离婚**:教堂找神父 → 发离婚请求 → 双方同意解除;己方爱情值高出配偶 1000+ 可单方面离婚。惩罚:爱情值清零、魅力 -5%、婚戒消失。

## 10. 宠物社区

**老版「企鹅岛」**:学校、储藏室(喂/洗/吃药)、医院、打工街、教堂,每个 NPC 一个活动。

**2009 新版五大场景**:
- 风语广场(教堂、古堡森林/古堡战记入口)
- 夏帕海岸
- 企鹅镇
- 粉钻雪山(粉钻专属,领礼包)
- 瓦里步行街(购物/装扮)

NPC「布袋长老」:宝石换成长药水;新手任务"布袋长老送信"(点亮 NPC 得装扮礼包)。

## 11. 旅游

- 条件:≥5 级;打工/学习/游戏/生病中不可。入口:右键菜单「宠物旅游」。
- 三种:拜访好友 / 逛好友圈 / 随便逛逛(神秘之旅)。
- 旅游期间心情 +5/分钟;神秘之旅随机奇遇,"梦想奖励"按累计次数递增 380~5000 元宝;途中随机捡宝箱和钥匙,配对开奖。
- 回家后文字汇报见闻,可能带回"小客人"(好友宠物来串门可互动)。
- ⚠推测:目的地/费用/时长表(建议按五大场景+好友家,固定路费+时长档)。

## 12. 任务 · 签到 · 周常福利

- 每日任务:每天 1 次,完成必得奖励(粉钻 2 次);每日登录签到有礼。
- 周常免费福利:5 级+ 每天嘉年华「牛翔赛跑」1 次(赢沐浴球);10 级+ 每周末寻宝 1 次(5~50 元宝/物品);周末许愿树(50/100/200 元宝);6 级+ 每天免费捕鼠夹(最高 80 元宝)。
- ⚠推测:具体任务列表。

## 13. 小游戏

- **桌面互动**(加心情):弹力球、躲避老鼠、跳绳、猜动作。
- **社区游戏**(产元宝):古堡战记(横版格斗,打长毛怪/科学怪人/狼人 Boss,日常一局 ≈15 元宝、Boss 100+);密室探险(俯视角迷宫,在教堂,通关得日用品/食物);狩猎场(竞技赚元宝)。粉钻曾不限次,后改 3 次/天(平民有限次)。
- 注意:宠物连连看、Q宠大乐斗是独立衍生产品,不属于本体。本体没有"武林大会"比武系统,"武"只体现为武力值属性+排行榜。

## 14. 经济系统

- **元宝**(主货币):获得 = 打工、奖学金、任务、寻宝/许愿树/捕鼠夹、旅游奇遇;充值 1 Q币 = 100 元宝(单向)。
- **消耗锚点**:挂机维持 ≈10 元宝/小时(饥饿+清洁各 -120/时)——"挂机也烧钱"是整个商业模型核心。
- **Q币**:还魂丹、豪华戒指、装扮、改名卡、粉钻包月。
- 乐扣贝:社区活动的第三货币,资料很少,单机版可不做。

## 15. 粉钻贵族(10 元/月)

特权:购物八折、每天一次免费用餐+免费清洗、免费看病、**免费托管**(不在线也不掉属性——最硬的特权)、名品城专属带属性物品、粉钻俱乐部礼包、交通工具/装扮泡泡免费试用、玫瑰园免费征婚、每日任务 2 次、社区游戏多次数、还魂丹 8 折。
(单机版可把"粉钻"做成一个可开关的作弊/舒适模式。)

## 16. 装扮

- 服装/装扮泡泡/交通工具/家具;瓦里步行街购买、任务礼包、活动奖励;名品城付费装扮带属性加成;改名卡付费改名。
- ⚠推测:具体清单/槽位/价格(建议头/身/手持/背景四槽)。

## 17. 桌面交互(复刻灵魂,优先级最高)

- **随系统启动/随 QQ 登录自动弹出**,从屏幕右下角出场(可在设置关闭——但当年默认开启且很难找)。
- **桌面行为**:在桌面走动、吃饭、睡觉、敲屏幕"玻璃";饿了哭、脏了挠痒;气泡对话提示状态;点击不同身体部位不同反应(点手/脚指挥动作)。
- **拖拽物理**:左键拎起 → 挣扎动画;高处松手 → 自由落体 + 落地翻跟头;**拖到屏幕边缘 → 藏起来只露一双眼睛**。
- **双击身体** → 快速喂养框;**双击托盘图标** → 召回。
- **右键菜单**(⚠顺序需推测):喂食 / 洗澡 / 逗玩·小游戏 / 看病吃药 / 打工 / 学习 / 宠物旅游 / 进入社区 / 我的家 / 宠物资料·名片 / 免打扰模式(暂停成长,喂食洗澡或双击自动解除)/ 隐藏宠物 / 系统设置 / 退出宠物(退出后不生长也不会死)。
- 状态面板:头像 + 四条属性条 + 等级/成长值 + 元宝数。
